# ffprobe distribuído para validação local

Wrapper npm @ffprobe-installer/ffprobe 2.1.2, LGPL-2.1, https://github.com/SavageCore/node-ffprobe-installer . Versões exatas por plataforma no package-lock.json; Linux x64 @ffprobe-installer/linux-x64 5.2.0 GPL-3.0, origem indicada pelo pacote https://johnvansickle.com/ffmpeg/ . Windows x64 5.1.0 GPL-3.0, origem https://www.gyan.dev/ffmpeg/builds/ . Não confundir licença do wrapper com a dos binários FFmpeg. Fontes/licenças upstream https://ffmpeg.org/legal.html e https://johnvansickle.com/ffmpeg/ . Nenhum binário é versionado no Git.

Build copia somente plataforma atual para vendor/ffprobe(.exe); lock npm fixa integridade do pacote. Bundle Vercel inclui vendor/** e não todas plataformas. Código executa processo separado, sem linkar biblioteca FFmpeg. Distribuição da imagem/binário deve preservar avisos e obrigações GPL/source correspondentes; confirmar pacote e proveniência no runtime antes da publicação. Builds empacotados não são versão FFmpeg upstream mais recente: atualização/patch/security review é obrigação contínua. Conteúdo inválido é não confiável; executar com timeout, argumentos sem shell, protocolos file somente e saída limitada.
