# Editor de granadas — Implementation Plan

Goal: três etapas e rascunhos seguros locais preservando mídia/radar.
Architecture: LineupForm continua proprietário do estado; painéis ocultos permanecem montados. localDraft contém apenas campos permitidos; chave por conta e cadastro; recuperação explícita, aviso de versão remota divergente.
Tech Stack: React/TypeScript, Vitest e Playwright existentes.
Spec: missão do usuário no chat e docs/continuity/frontend.md.

## Global Constraints
Sem backend, contratos, flags, limites, serviços reais, merge ou deploy. Sem persistir mídia, URLs ou segredos. Não restaurar File após reload.
